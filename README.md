### 🚀 Sideload it (because I'm not paying Google $25 to put it on Play Store)

1. Grab the APK from **[Releases](https://github.com/mohammed-imthiyaz/oneui-pixel-aura/releases)**.
2. Turn on **Wireless Debugging** on your watch (*Settings > Developer options*).
3. Run:
   ```bash
   adb connect <WATCH_IP>:<PORT>
   adb install -r com.watchfacestudio.oneuipixelaura.apk
   ```
4. Long-press your watch face, tap **Add**, and enjoy ;).
