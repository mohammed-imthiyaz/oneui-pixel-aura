# One UI Pixel Aura

A clean, minimalist Pixel lockscreen aesthetic for Galaxy Watch & Wear OS.

## ✨ Highlights
- **Google Sans typography** with motion parallax gyro aura
- **5 Material You colorways** (customizable on watch)
- **OLED-friendly AOD** (pure black background, zero extra battery drain)
- **Watch Face Format (WFF)** native support (Wear OS 4 / 5+)

---

## 🚀 Quick Install (ADB)

1. Grab the APK from **[Releases](https://github.com/mohammed-imthiyaz/oneui-pixel-aura/releases)**.
2. Enable **Wireless Debugging** under *Settings > Developer options* on your watch.
3. Install via terminal:
   ```bash
   adb connect <WATCH_IP>:<PORT>
   adb install -r com.watchfacestudio.oneuipixelaura.apk
   ```
4. Long-press your watch face, tap **Add watch face**, and select **One UI Pixel Aura**.
